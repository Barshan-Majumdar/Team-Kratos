Role definitions

  • Super admin — Crew platform operator (above all tenants)
  • CEO / Owner — highest org-level authority
  • HR Admin — full HR operations control
  • Manager — team-scoped approvals and visibility
  • Employee — self-service, own data only

System-locked features

Security, fraud detection (spatial trust, liveness, proxy detection), the audit trail, and RBAC itself cannot be modified even by the CEO. These are architectural guarantees, not configuration.

CEO override scope

CEO can promote or restrict access to any non-system-locked feature for any role. Changes are tracked and shown with an "edited" badge. Reverting a feature to its default removes the override.
