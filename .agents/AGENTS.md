# Antigravity Design & Frontend System Rules

This file establishes mandatory design standards, aesthetic guidelines, and skill activation rules for all UI/UX and frontend engineering tasks in this workspace.

---

## 🎨 Design System & Aesthetic Principles

1. **Anti-Slop AI Aesthetics Directive**:
   - Never use standard template defaults (e.g. basic centered heroes with purple gradients, standard 3-column equal card grids, default browser fonts, or static uninspired buttons).
   - Use HSL-calibrated color tokens, multi-layered elevation (`#08090D`, `#10121A`, `#181B26`), and ambient glow shadows.

2. **Typography & Hierarchy**:
   - Pair display headings (*Outfit*, *Space Grotesk*, *Playfair Display*) with hyper-legible body typography (*Plus Jakarta Sans*, *Inter*, *JetBrains Mono*).
   - Use fluid `clamp()` type scaling for seamless responsiveness across mobile, laptop, and ultra-wide displays.

3. **Interactivity & Micro-Motion**:
   - All interactive elements (buttons, cards, links, inputs) must feature explicit hover, focus-visible, active, and disabled states.
   - Use hardware-accelerated CSS transitions with custom cubic-bezier spring curves (`cubic-bezier(0.34, 1.56, 0.64, 1)`).

4. **Accessibility (WCAG 2.2 AA)**:
   - Ensure a minimum text-to-background contrast ratio of 4.5:1.
   - Provide clear high-contrast focus rings (`:focus-visible`) for keyboard navigation.
   - Use explicit semantic HTML5 markup (`<header>`, `<main>`, `<nav>`, `<section>`, `<article>`, `<aside>`, `<footer>`) and ARIA roles where applicable.
